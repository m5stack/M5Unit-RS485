Detailed Description

Non-instantiable base class for RS-485 transceiver units.

Constructor & Destructor Documentation

◆ RS485Component()

m5::unit::RS485Component::RS485Component ( RS485Component && other)
protectednoexcept

Move constructor.

Parameters
otherComponent to move from

The serial backend is taken over and told about its new owner, so a backend that points back at the component it serves (UnitSIT3088 drives the DIR pin through the unit) follows the move. The moved-from component is left with the null-behavior backend, so its Serial-compatible methods keep answering.

Note
Protected on purpose: moving through a reference to this base would hand a backend built for one unit to a component of another type. The concrete units declare their own move members, so a unit is movable as a unit.
Do not move a unit once UnitUnified::add() has registered it: UnitUnified keeps the address it was given, and the links to a parent or child component are copied rather than redirected.
Recreate any UnitSP485Stream that wraps the unit: it holds a reference to the component it was built from, which after a move answers through the null backend.

template<typename T , bool LittleEndian = true>
bool m5::unit::RS485Component::readValue ( T & value)
inline

Read a trivially copyable value.

Template Parameters
TType (must be trivially copyable and standard-layout)
LittleEndianIncoming data is little-endian if true
Parameters
valueReceive variable
Returns
True if successful
Note
LittleEndian byteswap is applied for integral / enum types and for 32-bit / 64-bit floating-point types (via bit-cast). Aggregate / struct types are stored as-is in host byte order; the LittleEndian parameter is ignored for those.
LittleEndian only declares the wire byte order; the peer must agree on the same convention. Floating-point special values (NaN, +/-inf, +/-0) are byte-reversed as raw bit patterns without special-casing.
Waits for sizeof(T) bytes with the backend's own timeout, as the two-argument readBytes() does: the one set by HardwareSerial::setTimeout() on Arduino, and a fixed 1000 ms on ESP-IDF native. Use readBytes() with an explicit timeout to control it.
sizeof(T) must be 256 bytes or less: the value goes through a stack buffer, and 256 bytes is the largest Modbus RTU frame as well as this library's default RX buffer size.

Deleted: the second argument of write() is a byte count.

Rejects what cannot be a count – char and signed char (write(buffer, 'a') would otherwise mean 97 bytes), bool, and any non-integral type, including the bool-convertible proxies of std::vector<bool> / std::bitset<N>, which used to slip through as a length. An integer length is filtered out by SFINAE and keeps resolving to write(const uint8_t *, size_t).
